## How I work

- **Architecture:** Domain-Driven Design, microservices, CQRS and the C4 model. I draw the boundaries before I write the code.
- **Back end:** C# and ASP.NET Core, Node.js, Python, Kotlin. SQL on PostgreSQL and MySQL; Supabase and serverless when the project calls for it.
- **Front end:** React and Next.js, Vue, TypeScript and Tailwind CSS, with GSAP and Three.js for motion and 3D.
- **Local AI:** I run open-weight models (Llama, DeepSeek) on my own GPU and build tools around them.
